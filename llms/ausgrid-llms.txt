# Ausgrid

> Ausgrid is the electricity distribution network service provider (DNSP) for Sydney, the Central Coast and the Hunter Valley in New South Wales, Australia, serving more than 1.8 million customers. It operates the poles, wires and substations; it does not sell energy. **Ausgrid publishes no API, no developer portal and no machine-readable contract of any kind.** This file is generated by API Evangelist from verified probes — it exists so an agent stops looking for an API that is not there, and finds the data that is.

## What does not exist

- No OpenAPI/Swagger: `/openapi.json`, `/swagger.json`, `/api-docs` return 404 on www, services and dtapr hosts; on idoportal they 302 to a generic error page.
- No GraphQL, no AsyncAPI, no webhooks, no MCP server, no SDK, no CLI, no Postman collection, no GitHub organisation.
- No `/.well-known/` discovery: security.txt, openid-configuration, oauth-authorization-server, oauth-protected-resource, api-catalog, ai-plugin.json all 404.
- No OAuth 2.0, OpenID Connect, API key or mutual TLS on any surface.
- No Consumer Data Right obligation: the CDR energy designation lands on electricity retailers with AEMO as gateway. Ausgrid is absent from the 84 brands returned by the public CDR energy data-holder register.

## Open data you can actually get, anonymously

- [Research data sets index](https://www.ausgrid.com.au/about-us/about-ausgrid/research-data-sets): the catalogue page for everything below.
- [Distribution zone substation data](https://www.ausgrid.com.au/about-us/about-ausgrid/research-data-sets/distribution-zone-substation-data): 15-minute interval demand in MW for 180+ zone substations, one ZIP of CSV per financial year, 2005 through 2025. No login, no key, no agreement. Published under National Electricity Rules 5.13A, May-to-May reporting year, within 30 business days of the DTAPR.
- [Average electricity use](https://www.ausgrid.com.au/about-us/about-ausgrid/research-data-sets/average-electricity-use)
- [Electricity research](https://www.ausgrid.com.au/about-us/about-ausgrid/research-data-sets/electricity-research)
- [Ausgrid on the NSW Government CKAN portal](https://data.nsw.gov.au/data/organization/ausgrid): 3 datasets, CC-BY. Note the catalogue's resource links still point at retired `/Industry/Our-Research/Data-to-share/` paths that now 404, and the CC-BY licence in the catalogue contradicts Ausgrid's own page, which asserts sole ownership of the data.
- [DTAPR data portal](https://dtapr.ausgrid.com.au/): Ausgrid's Distribution and Transmission Annual Planning Report web application (feeder forecasts, 11kV feeder capacity, generation hosting capacity). A Rosetta Analytics application serving flat files from `./ausgrid_data/`; it exposes no API.

## Queryable machine-readable surface (NOT operated by Ausgrid)

Ausgrid-owned network planning and hosting-capacity data is exposed as anonymous ArcGIS REST FeatureServer layers on the **NSW Government** portal. The data carries `owner="Ausgrid"`; the endpoints belong to NSW Government, not to Ausgrid.

- `https://portal.data.nsw.gov.au/arcgis/rest/services/Hosted/Ausgrid_DTAPR_2023/FeatureServer/0` — 8,696 feeder and sub-transmission line segments (object, name, voltage, dual_function).
- `https://portal.data.nsw.gov.au/arcgis/rest/services/Hosted/Ausgrid_UHC_Data/FeatureServer/0` — 2,160 primary-voltage unallocated hosting capacity records (substation, year, available load and generation capacity at N-1).
- `https://portal.data.nsw.gov.au/arcgis/rest/services/Hosted/Ausgrid_UHC_Data/FeatureServer/1` — 2,120 secondary-voltage records, plus N-1 nameplate capacity.
- Conventions: `f=json|geojson|pbf`, SQL-style `where`, `outFields`, `resultOffset`/`resultRecordCount` paging, `maxRecordCount` 2000. Errors come back as HTTP 200 with `{"error":{"code","message","details"}}`.

## Consumer meter data — no API

A customer's own interval meter data is obtained through [a web form](https://www.ausgrid.com.au/your-energy-use/your-meter-and-supply/access-your-meter-data) that verifies NMI, account holder name and postcode; a third party must attach a signed consent form. Fulfilment is 10 business days for one NMI, up to 20 for several, in AEMO meter-data-provision format, by email. There is no programmatic path and no consent API.

## Undocumented internal routes — do not build on these

`https://www.ausgrid.com.au/api/outages-map/*`, `/api/forms/*`, `/api/reporting/*`, `/api/search`, `/api/healthz` are Next.js route handlers powering ausgrid.com.au itself. They are anonymously reachable and return JSON, but they are undocumented, unversioned, carry no published terms and are not offered to developers.
